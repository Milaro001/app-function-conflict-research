# 来源选择与运行状态

2026-10-26用户解除微博暂缓、启用抖音，并要求核心覆盖小红书、微博、知乎。这里的覆盖是必须尝试检索并交代结果或缺口，不是承诺平台允许取得全部内容。公开内容、账号允许访问的内容与受限内容应区分记录。

## 固定基础与议题补充

| 来源 | 决策 | 对网易云音乐研究的用途 | 必须分开的材料 |
|---|---|---|---|
| 应用宝 | 保留基础来源 | App评价、评分、发布时间等结构信息 | scripts/appbao.py免登录采集；评论属安卓条目但作者设备、版本未写明；历史评论与近期评论 |
| App Store | 免登录补充来源 | iOS评价，带版本号与评分，适合查版本前后变化 | 标记client=ios，不计入仅安卓范围；RSS仅最新约500条 |
| 公开网页补证 | 通道失败或无适配器时 | 投诉平台、贴吧、论坛、问答的公开原文 | 只收取得原始页面的原文摘录；检索摘要不计入 |
| 小红书 | 核心社媒 | 使用经历、改版、皮肤、付费与场景 | 交易/求皮肤/教程跟帖与亲历反馈；图片未核验 |
| 微博 | 核心社媒，重新启用 | 事件发生时间、传播语境、公开吐槽及澄清 | 热搜/转发量不当作需求票数；纯事件表态不填功能样本 |
| 知乎 | 核心社媒，已接入适配器，待登录实测 | 问题—回答—评论链，功能取舍与解释假设 | 回答作者的分析不等于使用者经历；旧答案和后续更新区分 |
| B站 | 已有能力，议题补充 | 改版演示、使用评测及评论 | 视频未解读时只分析文字；教程内容与用户问题分开 |
| 抖音 | 用户已启用，试采中 | 短视频中的使用问题与评论，补充来源视角 | 视频语境依赖、跟风表态、公开评论范围 |
| 即刻 | 定向补证，不默认扩量 | 音乐App迁移、发现音乐与社区取舍；也可找设计假设 | 从业者视角不代替普通使用者；无需默认假定作者职业 |
| 豆瓣 | 公开指定话题/小组补证 | 音乐使用方式、歌单、版权、社区与付费语境 | 歌手/作品评价与App功能反馈分开；不可得楼层明确缺口 |
| 脉脉 | 本题不作默认来源 | 未来职场App、行业工具、企业服务研究时启用 | 公司/雇主/裁员舆情不等于消费者功能反馈；不据职业自述推断身份 |
| V2EX、小众软件论坛 | 定向补证 | 替代工具、客户端差异、专业使用场景 | 小群体意见与广泛使用者分开 |

这是按研究任务作出的来源建议，不是平台可信度排名。任何来源都按同一P/V/C/U/G/E规则筛选，不按“专业人士”“高赞”自动提高证据等级。一个来源的巨大样本量不能掩盖其他核心来源完全不可得。

## 技术接入

当前固定MediaCrawler版本包含小红书、微博、知乎、B站、抖音、快手、贴吧模块；即刻、脉脉、豆瓣不在该版本的适配目录。前三者可从公开链接检索、用户提供链接/导出、人工核对开始，不能虚称同一开关即可全自动采全。

知乎需要保留问题标题、问题说明、回答原文和更新时间、评论及可得回复对象。搜索摘要只作线索，未取得原文不计合格反馈。长回答可以提取多个主张，回答与短评论分层展示，不靠拆句凑样本。现有1000条目标沿用合格评论口径；回答、文章、视频说明等作为独立材料单列，未经范围调整不拿来填评论目标。

抖音的本地试验使用专用Edge正常导航、滚动、点击可见回复，记录正常页面返回的JSON；沿用固定MediaCrawler字段结构，不重放或伪造网关验证头，不切代理或身份绕过拒绝。记录采集通路，避免把浏览器适配器误称上游接口原样跑通。

微博上游只返回嵌入式回复预览时，标记embedded_preview_only，不能声称楼中楼完整。各站分别报告登录复用、搜索翻页、主评论翻页、回复翻页及缺失上下文，不采用“七个平台都正常”的总开关结论。

## 采集调度

1. 应用宝保留为基础；小红书、微博、知乎必须检索并记录结果/限制；B站、抖音按本轮启用范围试采。
2. 关键词同时覆盖中性对象与任务（网易云音乐/播放器/歌单/日推/社区/会员），再用问题词与保留偏好词定向补证。不能全用“难用/垃圾/退款”造成只采负面。
3. 技术试采与正式研究分开。当前项目按用户2026-10-26修订：每个已启用社媒先取得至少10条近期相关帖/视频/回答的实际正文，按发布时间从新到旧呈现；评论与可得回复另外统计。平台允许时间排序时启用该排序，再人工或模型判断与产品功能的相关性；多关键词合并去重后按实际发布时间排。不把搜索摘要算已采正文，也不宣称取得全站绝对最新10条。广告、教程与亲历反馈分别标记，不能为凑10条纳入无关内容。来源不足或受限时记录实际数量、检索范围与缺口；不以其他来源补齐该站。
4. 跨站同文、转述与事件搬运关联去重；热度仅表示来源内传播，不作为独立使用者数量。
5. 登录/验证码由用户完成，登录态按专用资料复用；受限停止该路径。输出实际取得量和筛后量，不为补平台或凑1000而降低标准。

近期帖子覆盖使用`scripts/recent_sample.py`：先`discover --platform xhs --app 抖音 --keyword "抖音 功能" --keyword "抖音 改版" --pages 2`取得时间排序线索，再阅读`candidates.json`，以`sample --platform xhs --app 抖音 --source-run <运行号> --post-ids <逗号分隔ID> --comments`读取选定帖正文与评论。小红书、微博、B站、知乎已提供该入口，抖音沿用正常页面动作通路。可用`--keyword-plan`读取keywords.py矩阵、`--auto-select N`自动选帖。带访问参数的搜索原始项只留在私有runtime；交付仅含正文和必要来源字段。每批最多60帖、3000条评论、12个关键词；先取得帖正文，再按限额读取评论，评论路径失败后不反复探测。
