# Human Gate 卡

## G1 · 冻结范围规则与变更

- Gate 名称：冻结范围规则与变更。
- AI 提供什么：默认来源与时间、检索和停止规则、五项呈现约束、变更与缺项清单。
- 看什么：①目的与对象匹配 / ②来源可执行 / ③范围清楚 / ④停止规则明确 / ⑤呈现约束可用。
- 能做什么：确认并保存 / 修改后确认 / 退回重拟 / 暂停变更。
- 不通过回哪：回步骤2「应用规则并生成计划」（N2）。已有规则仍适用时引用原决定，不伪造新审批。

冻结范围；首次设定或重要变更时介入。

## G2 · 裁定证据解释与结论边界

- Gate 名称：裁定证据解释与结论边界。
- AI 提供什么：网页实稿、议题和双向原文、上下文与版本、覆盖缺口、编码及排序理由、校验报告。
- 看什么：①引文可回查 / ②语境与条件可比 / ③冲突成立 / ④统计准确 / ⑤推断边界清楚。
- 能做什么：通过 / 标明限制后限用 / 要求补证 / 退回重编码；呈现错误交N7修复。
- 不通过回哪：补采回步骤4「复用会话并采集证据」（N3）；语义回步骤6「提取主张并判别冲突」（N5）；呈现回步骤8（N7）。

承担研究判断责任；在网页内集中复核。

## G3 · 选择迭代行动与使用方向

- Gate 名称：选择迭代行动与使用方向。
- AI 提供什么：每项机会的原文依据、原因假设与反例、候选改法、代价、适用条件及最小验证任务。
- 看什么：①证据对应 / ②双方任务受保护 / ③条件明确 / ④代价与未知可见 / ⑤验证可行。
- 能做什么：采纳为设计任务 / 先做验证 / 要求补证 / 暂缓 / 退回方案。
- 不通过回哪：方案不合适回步骤7「深挖原因并形成迭代建议」（N6）；新证据缺口经G2回N3或N5，修改后重过后续检查。

承担行动选择责任；可与G2同轮操作。
